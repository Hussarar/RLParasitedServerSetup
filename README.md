# RLParasitedServerSetup
This is a small script that will generate a RLCraft Parasited Server for you.
You can select what type of server it is

<!-- Bulleted List -->
* RLCraft Parasited
* Dregora Parasited
* ShyCraft Parasited

and what configuration you would like to add.
<!-- Bulleted List -->
* Unparasited
* HCC
* OmegaHCC

You can add mods that you would like to remove in "removal_modlist.txt" be aware that the "Client Mods" already listed need to be deleted in order to start the server.
After the installation is completed you can use the boot_server.sh to start the server! (Don't forget to Portforward 25565 TCP&UDP)

You will need Java 8 and Python 3.12 for this Script to run without issues
